# DNA Sequence Analyzer

## About
A beginner-level bioinformatics project developed using Python to analyse DNA sequences.

## Objectives
- Calculate DNA sequence length.
- Count individual nucleotides.
- Calculate GC and AT content.
- Generate reverse complement.
- Identify start and stop codon motifs.
- Visualize nucleotide frequency.

## Tools Used
- Python
- Google Colab
- Matplotlib
